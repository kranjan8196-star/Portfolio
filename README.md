# Ranjan Kumar — React Portfolio

A responsive portfolio made with React + Vite, with the supplied portrait included.

## Public portfolio

The site will be available at https://kranjan8196-star.github.io/Portfolio/ after GitHub Pages is enabled for the repository with GitHub Actions as its build source. Once enabled, pushes to `main` automatically build and deploy the site.

## Easiest way to open on Windows

1. Extract the ZIP completely.
2. Install Node.js LTS from https://nodejs.org/ if it is not already installed.
3. Double-click `START_PORTFOLIO.bat`.
4. On the first run it installs the required packages, then opens the website in your browser.

## Run manually

Open a terminal in this folder and run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Build a production version

```bash
npm run build
npm run preview
```

Vite uses the `/Portfolio/` base path required by this GitHub Pages project site.

## Project structure

- `public/ranjan-kumar-portrait.png` — supplied portrait
- `src/App.jsx` — React page and content
- `src/main.jsx` — React entry point
- `src/styles.css` — responsive gradient styling
- `index.html` — Vite app entry
- `START_PORTFOLIO.bat` — Windows launcher
